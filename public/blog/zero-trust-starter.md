# ゼロトラスト入門: はじめの一歩

境界防御から「常に検証」へ。まずは現実的にできる施策から。

## 最初の3ステップ
- [x] ID基盤の強化（MFA/パスワードレス）
- [x] デバイスの健全性チェック（MDM/EDR）
- [ ] コンテキスト認可（場所/時間/リスク）を段階導入

## 方針テーブル
| 領域 | 最初の一手 |
|---|---|
| ID | MFA/条件付きアクセス |
| 端末 | パッチ準拠/EDR必須 |
| ネットワーク | セグメント＋証明書ベース |

```sh
# リスクに応じてMFA要求を強化する疑似例
rule when risk >= medium then require_mfa
```

[^1]: 完全移行ではなく「段階的に適用範囲を拡張」するのが現実解。
